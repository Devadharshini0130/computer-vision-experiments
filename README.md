# Computer Vision – Image Processing Experiments

This repository contains three Python/OpenCV Computer Vision experiments.

## Experiments

### Experiment 1 – Classical Spatial Filtering
Mean, Gaussian, Median, and Bilateral filtering for image enhancement and noise reduction.

### Experiment 2 – Thresholding Techniques for Image Segmentation
Global, Adaptive Mean, Adaptive Gaussian, and Otsu's thresholding.

### Experiment 3 – Edge Detection Techniques
Sobel, Laplacian, and Canny edge detection for feature extraction.

## Requirements

```bash
pip install -r requirements.txt
```

Each experiment contains:
- `program.py` – source code
- `output.png` – combined output figure
- `README.md` – experiment details

Add an `input.jpg` image to the corresponding experiment folder before running its program.
