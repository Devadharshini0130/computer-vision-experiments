# Experiment 3 – Edge Detection Techniques

## Aim
To implement and analyze Sobel, Laplacian, and Canny edge detection techniques using Python and OpenCV for extracting significant object boundaries and structural features from an image.

## Techniques Used
- Sobel Operator
- Laplacian Operator
- Canny Edge Detector

## Files
- `program.py` – Python/OpenCV implementation
- `input.jpg` – Input image (add your preferred image here)
- `output.png` – Combined execution output

## Run
```bash
pip install opencv-python matplotlib
python program.py
```

## Result
The edge detection techniques were successfully implemented. Sobel detects directional intensity gradients, Laplacian emphasizes rapid intensity changes, and Canny produces thin and well-defined edges using a multi-stage detection process.
