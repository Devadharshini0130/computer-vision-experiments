# Experiment 1 – Classical Spatial Filtering

## Aim
To implement and analyze Mean, Gaussian, Median, and Bilateral spatial filtering techniques using Python and OpenCV for image smoothing, noise reduction, and edge preservation.

## Techniques Used
- Mean Filter
- Gaussian Filter
- Median Filter
- Bilateral Filter

## Files
- `program.py` – Python/OpenCV implementation
- `input.jpg` – Input image (add your preferred image here)
- `output.png` – Combined execution output

## Run
```bash
pip install opencv-python matplotlib
python program.py
```

## Result
The four spatial filters were successfully implemented and compared. Mean and Gaussian filters provide image smoothing, Median filtering is effective for impulse noise, and Bilateral filtering reduces noise while preserving important edges.
