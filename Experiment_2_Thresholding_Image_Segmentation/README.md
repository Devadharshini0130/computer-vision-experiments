# Experiment 2 – Thresholding Techniques for Image Segmentation

## Aim
To implement and analyze Global (Fixed), Adaptive Mean, Adaptive Gaussian, and Otsu's Automatic Thresholding techniques using Python and OpenCV for foreground-background image segmentation.

## Techniques Used
- Global (Fixed) Thresholding
- Adaptive Mean Thresholding
- Adaptive Gaussian Thresholding
- Otsu's Automatic Thresholding

## Files
- `program.py` – Python/OpenCV implementation
- `input.jpg` – Input image (add your preferred image here)
- `output.png` – Combined execution output

## Run
```bash
pip install opencv-python matplotlib
python program.py
```

## Result
The thresholding techniques were successfully implemented. Global and Otsu thresholding use a single global threshold, while Adaptive Mean and Adaptive Gaussian thresholding calculate thresholds using local image regions.
